# KPI Dictionary

| KPI | Definition | Business use |
|---|---|---|
| Generation MWh | Sum of hourly net generation | Portfolio production volume |
| Gross Margin | Market revenue − fuel cost − variable O&M | Commercial performance |
| Margin / MWh | Gross margin ÷ generation | Unit economics |
| Availability % | Average hourly availability flag | Asset operating readiness |
| Capacity Factor | Generation ÷ nameplate capacity-hours | Asset utilization |
| Realized Capture Price | Revenue ÷ generation | Price actually captured by production profile |
| Forecast Error % | Absolute actual-minus-forecast ÷ actual | Forecast monitoring |
| Curtailment MWh | Simulated available renewable output not generated | Renewable operational constraint proxy |
| Economic Spread | Real-time price − variable production cost | Thermal dispatch economics |
| Estimated Incremental Margin | Simulated headroom × positive spread × conservative realization factor | Opportunity-screening metric only |

## Important caveat
`Estimated Incremental Margin` is intentionally a simplified analytical screen. Real-world dispatch decisions require unit constraints, start costs, minimum run times, transmission constraints, fuel contracts, hedges, market rules, and operator judgment that are outside this synthetic case study.
